// 02 Under the hood

Three layers, no shortcuts

Deliberately kept close to the metal so each layer's job stays visible.

Frontend
HTML
Plain forms and tables — every input maps directly to a column, every submit to a Servlet endpoint.
Backend
Java Servlets
doGet / doPost handle routing, request parsing, and call the DAO layer that talks to JDBC directly.
Database
MySQL via JDBC
Connection pooling, PreparedStatements, and raw ResultSet handling — the exact things an ORM would hide.
// 03 Why build this

The learning path this project follows

Built in order, so each step forces the next concept.

1. Connect
Load the driver, open a Connection, handle SQLException properly instead of swallowing it.
2. Define schema from code
Let the user create databases and tables dynamically — forces real understanding of DDL vs DML.
3. Bind parameters safely
Replace string-concatenated SQL with PreparedStatement to prevent injection and learn placeholder binding.
4. Read results back
Iterate a ResultSet, map rows to objects, render them — the R in CRUD, done manually.
5. Wire it to Servlets
Every form action becomes a doPost/doGet, tying frontend intent to backend SQL execution.
